# rubik-timer
ルービックキューブのタイマーアプリ。iPhone の Chrome を含むモダンブラウザ向けの、依存パッケージ不要の静的 Web アプリです。

## 起動

Python 3 を用意し、このディレクトリで `python3 -m http.server 8000 --bind 0.0.0.0`（または `npm start`）を実行します。公開するときは、このディレクトリを HTTPS 対応の静的ホスティングに配置してください。

## 操作

- 大きなタイマー領域をタップして開始・停止。PC ではスペースキーでも操作できます。
- 停止時に記録をブラウザの localStorage に保存します。同じ端末・ブラウザ・オリジンで再表示できます。プライベートブラウズ終了やサイトデータ削除で消えることがあります。
- Ao5 は直近5回の最速・最遅を各1回除いた3回の平均です。5回未満では表示しません。削除後は残った記録から再計算します。
- × で個別削除、「すべて削除」で確認後に全件削除します。

## 検証

Node.js で `npm test` を実行します。ビルドや API キー、外部サービスは不要です。
